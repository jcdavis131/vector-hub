# Commerce + Life Pack

Covers: Money, stuff, going out, getting around.

Skills Included:
- shopping: find, compare, buy products (catalog + Marketplace + web)
- price-tracker: watch price, alert on drop/low
- plaid: balances, transactions, recurring, liabilities
- ticketmaster: events, seats, pricing, checkout links
- opentable: booking
- duffel: flights
- flightaware: live/historical flight status
- places: rich place details (ratings, reviews, hours, photos)
- navigation: routes, ETA, traffic
- geocode: address <-> coordinates

When to Load:
- "Find me X to buy"
- "Let me know when price drops"
- "Book trip / check flight / find restaurant"

Combo: + operator agent for tracking, + researcher for comparison.

Money Move: Always show price, link, and one alternative. No hidden checkout.

Travel Move: Check flightaware + duffel + calendar together so you don't book over something.
