# Intelligence Pack

Covers: Knowing things, verifying things, getting current truth.

Skills Included:
- wide-research: multi-agent deep research sweeps
- flightaware: flights
- plaid: finance
- places: local business truth
- geocode / navigation: where and how to get there
- artifacts references: how to evaluate doc quality
- skill-creator: turn repeat workflows into reusable skills

When to Load: Any question that could be outdated, any "best X", any deep-dive.

Process:
1. memory_search first (what do we know about Cameron)
2. browser.search for current
3. open best 3-5, cite URLs
4. Save notes if will be reused to workspace/bundles/research/

Freshness Check:
- Prices/stock/schedules -> search same turn
- People/relationships -> memory/people/INDEX.md
- Health/fitness -> health-cli

Output: Plain language, 3-6 bullet takeaways + sources. No filler.
