# deep-research-pack v3.2 — Scout's Deep Research Engine (OODA + Agentic)

When: truth matters more than speed. Best X, pricing, health, people, anything stale. OODA heavy, agentic production-grade.

## OODA Link Explicit for Every Node

- **Observe:** Real-time data gathering sensory info snapshot imperfect. Wide Sweep 5-7 parallel parallel searches OODA Observe. Recognize complexity all data snapshot.
- **Orient:** Filter/analyze using culture, past experience, genetics, analysis prior + new info, org culture, org learning. Orientation shapes quality of later Decide/Act more than raw speed. Better orientation > just faster. Memory lattice + culture + experience + new data synthesis.
- **Decide:** Formulate plan/hypothesis to test. Synthesist's job.
- **Act:** Execute, artifact changes env, generates new observation.
- **Feedback Loops:** Cybernetic not linear. Continuous feedback. Orientation never stops. Scientifically: decisions=hypotheses, actions=tests.
- **Speed vs Perfection & Tempo:** Imperfect quick action creates info waiting loses. Timing = rate + rhythm > raw speed. Late commitment agility vs PDCA early commitment. Bronze→Gold latency signal-to-action.
