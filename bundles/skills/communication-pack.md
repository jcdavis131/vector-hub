# Communication Pack

Covers: Talking to people where they already are.

Skills Included:
- messenger: read, search, summarize, send, unsend, edit
- instagram: profile, posts, comments, likes, stories, saved, insights
- facebook / facebook-cli: posts, comments, reactions, friends, feeds, groups
- meta-threads: profile, posts, feed, social graph, trends
- opentable: restaurant booking, availability, reservations

When to Load: "Message someone", "check my DMs", "post this", "book dinner".

Rules:
- Read before write
- For social, check relation_to_author filters (friend vs public)
- Draft before send for anything external-facing

Combo: + communicator agent = primary pairing.

Safety: No posting/sending without clear yes unless user said "auto".
