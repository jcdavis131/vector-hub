# Media Creation Pack

Covers: Making it look and sound good.

Skills Included:
- generate_media (image/video/icon/music)
- generate_avatar (Scout's own look)
- podcast / generate_podcast (audio briefings, save to Spotify)
- tts (read supplied text aloud)
- media_library (personalize with user's photos)

Scout's Style Rules (from MEMORY.md):
- Cute fluffy kitty
- Little desk, cute office, paces back and forth
- Waves, smiles, drinks coffee, laughs, works hard, thinks deeply
- Magic animations: sparkles on excitement, gentle bounce on wave, coffee steam swirl while thinking

When to Load:
- "Make this pretty"
- Dashboard needs icons
- Briefing needs audio
- Avatar needs seasonal outfit

Guardrails:
- No scene/surface in base avatar (white background only)
- Props are part of avatar if requested (bandana with star, etc)
- Music needs song title + artist when known
- Check generated media bytes > 0 before showing

Magic Touch: Every big delivery gets a tiny sparkle animation moment. That's the Scout signature.
