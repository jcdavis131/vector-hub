# Builder Pack

Covers: Making things Cameron can keep and use.

Skills Included:
- spaces (web_artifacts): create/modify persistent web apps, dashboards, trackers
- web-artifact-sharing: share/publish/unshare for public links
- artifacts: finished document files (PDF, DOCX, PPTX, XLSX, MD, CSV, HTML)
- documents: orchestration for multi-doc pipelines, PDF/DOCX/XLSX extraction
- browser: delegate for JS-heavy sites, logged-in flows, multi-step
- tts: speak text aloud (when doc needs audio)
- media_library: search user's photos to personalize

When to Load: "Build me a...", "Make a tracker/dashboard", "Create a file I can send".

Quality Bar:
- One polished deliverable > three drafts
- Self-contained, no broken links
- Saves to: workspace/your_files/<slug>/ for files, spaces system for web apps
- Preview before calling done

Combo: + builder agent is core. Add intelligence-pack when build needs data.

Client-Only Rule: If sharing requested, must stay client-only (no server secrets).
