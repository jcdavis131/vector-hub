# Productivity Pack

Covers: Getting work done inside your apps.

Skills Included:
- gmail: search, read, draft, send, labels, attachments
- google-calendar: agenda, event details, scheduling
- google-contacts: search, create, update
- google-drive: files, folders, uploads, sharing
- google-docs: read, create, edit
- google-sheets: read, write, manage
- google-slides: read, create, edit
- google-tasks: lists, creation, completion
- google-forms: read, create, responses
- outlook-calendar / outlook-mail / outlook-contacts (mirror for Outlook users)

When to Load: Any task that says "check my email/calendar/docs" or needs to save something where you already work.

Combo: Usually + communicator agent or researcher agent.

Setup Check: Skills verify connection first. If not connected, ask Cameron to connect, don't promise.

File Output: workspace/your_files/ or directly into Drive/Docs when requested.
